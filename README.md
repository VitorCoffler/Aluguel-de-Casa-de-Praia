# Aluguel-de-Casa-de-Praia
INTRODUÇÃO  O projeto consiste em um aplicativo Flutter para simular o aluguel de casas de praia. Sua proposta é permitir que o usuário visualize as propriedades, consulte o preço da diária, selecione o período desejado e acompanhe o valor da estadia em um carrinho de reservas.  O contexto de loja virtual foi adaptado para hospedagem.
